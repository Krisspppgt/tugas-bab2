## 🌐 Cara Hosting ke Vercel (Gratis & Cepat)

### Cara 1: Lewat Dashboard Vercel + GitHub (Direkomendasikan)
1. Buat repositori baru di [GitHub](https://github.com/).
2. Upload atau `push` folder `TUGAS-BAB2` ke GitHub.
3. Buka [Vercel](https://vercel.com/) dan login menggunakan akun GitHub.
4. Klik **"Add New..."** -> **"Project"**.
5. Pilih repositori GitHub tadi, biarkan settingan default, lalu klik **"Deploy"**.
6. Selesai! Website kamu langsung aktif online dengan domain `.vercel.app`.

### Cara 2: Lewat Vercel CLI (Terminal)
1. Buka terminal di folder `C:\TUGAS-BAB2`.
2. Jalankan perintah:
   ```bash
   npx vercel
   ```
3. Ikuti petunjuk login dan konfirmasi di terminal sampai proses deploy selesai.
